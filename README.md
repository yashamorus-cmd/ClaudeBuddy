# ClaudeBuddy 🧡

Маленький помаранчевий піксельний персонаж, який живе на робочому столі Linux:
гуляє по екрану, інколи бігає за курсором і каже фрази — поради, англійські вислови
з перекладом і українські цитати.

> Фанатський проєкт, натхненний маскотом із заставки Claude Code.
> Не пов'язаний з Anthropic.

## Що вміє

- гуляє у випадкові точки екрана (і між моніторами, якщо їх кілька), кліпає очима;
- інколи біжить за курсором (якщо його видно — див. «Обмеження»);
- каже фрази в хмаринці: поради, англійські вислови з перекладом, українські цитати;
- **реагує на Claude Code:** «Готово! ✅», коли Claude закінчив, і стрибає, коли чекає на дозвіл;
- **тамагочі:** ситість і настрій падають з часом; голодний бадді блідне й ходить повільніше;
- **слово дня** англійською, **вікторина** і гра **«Спіймай мене»**;
- **помодоро:** 25 хв роботи → бадді виходить на середину екрана й кличе на перерву;
- **засинає**, коли тебе довго немає (уночі швидше), і радіє, коли повертаєшся;
- **компаньйон** — котик, песик або курчатко, що ходить поруч;
- **погода:** у дощ тримає парасольку, у мороз і спеку дає пораду;
- сезонні образи на свята і **твій день народження**;
- **сам перезапускається**, коли змінюється його код, — оновлення видно одразу;
- завжди поверх вікон, але кліки повз персонажа проходять крізь нього.

## Керування

| Дія | Що станеться |
|---|---|
| Лівий клік | погладити: підстрибне й трохи повеселішає (сплячого — розбудить) |
| Подвійний клік | одразу скаже наступну фразу |
| Затиснути й тягнути | перенесеш його в інше місце |
| Правий клік | меню (див. нижче) |

### Меню

- **Ситість і настрій** — верхній рядок показує, як почувається бадді.
- **Погодувати 🍎** — падає яблучко, +25 ситості (наїдений — відмовиться).
- **Погратися ⚽** → **Вікторина** (обери переклад слова) або **Спіймай мене!**
  (20 секунд бадді бігає, а ти клацаєш по ньому; рекорд запам'ятовується).
- **📖 Слово дня** — нове англійське слово щодня; повторив — бадді радіє.
- **🍅 Помодоро** — почати / зупинити; у меню видно, скільки хвилин лишилось.
- **Скіни, Компаньйон 🐾, Сезонні скіни, 🎂 Мій день народження…**
- **🌦 Погода** — вкажи місто, і бадді стежитиме за погодою.
- **⚙️ Налаштування** — як часто говорить, про що говорить, сповіщення від Claude Code.
- **🔕 Не заважати** — без випадкових фраз, погоні за курсором і скарг на голод
  (сповіщення Claude Code і помодоро лишаються — ти їх сам увімкнув).
- **🔄 Перезапустити** і **Вийти**.

## Скіни 🎩

Правий клік → вибери аксесуар у кожному слоті (їх можна поєднувати):

- **Головний убір:** біні, корона, навушники, циліндр, кепка, ковбойський капелюх, вінок,
  кухарський ковпак, шолом вікінга, капелюх чарівника, кепка з пропелером
- **Обличчя:** окуляри, сонцезахисні окуляри, вуса, монокль, маска, рум'янець,
  окуляри-сердечка, піратська пов'язка, клоунський ніс
- **Одяг:** вишиванка, метелик, шарф, светр, фартух, костюм, плащ, гавайська сорочка, медаль
- **Компаньйон:** котик, песик, курчатко

Вибір запам'ятовується в `~/.config/claude-buddy/config.json`.

**Сезонні скіни** вдягаються самі (вимикаються галочкою в меню):

| Коли | Образ |
|---|---|
| Твій день народження | 🎂 святковий ковпачок і конфеті |
| 24–25 грудня | 🌟 різдвяна зірка і шарф |
| 15 грудня – 15 січня | 🎅 шапка Санти |
| Великдень (рахується сам) | 🥚 вишиванка і писанка |
| 25 жовтня – 2 листопада | 🎃 капелюх відьми, гарбузовий колір, світні очі |
| 1 жовтня | 💙💛 шолом і прапорець |
| День вишиванки (3-й четвер травня) | 🌻 вишиванка і вінок |
| 23–25 серпня | 💙💛 вишиванка і прапорець |
| 14 лютого | ❤️ сердечко над головою |

Сезон замінює лише ті слоти, які використовує: наприклад, шапка Санти замінить корону,
але сонцезахисні окуляри лишаться.

Подивитися сезонний скін у будь-який день:

```bash
BUDDY_DATE=2026-12-25 python3 buddy.py
```

### Як намалювати свій аксесуар

Відкрий `skins.py`: на початку файлу є схема сітки і покрокова інструкція.
Коротко — малюнок із символів, де `.` прозоро, а кожна літера — колір із `palette`:

```python
"cap": Accessory(
    name="Кепка",
    art=(
        "....GGGGGGGGGG....",
        "...GGGGGGGGGGGGGG.",
    ),
    palette={"G": (0.2, 0.7, 0.3)},
    row=-2,  # на 2 рядки вище голови
),
```

Додай його в словник `HEAD`, `FACE` або `BODY` — і він з'явиться в меню.

## Встановлення (Ubuntu / GNOME)

Потрібні Python 3 і GTK 3 з підтримкою Cairo:

```bash
sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0
```

Запуск:

```bash
python3 buddy.py
```

Персонаж може бути лише один: другий запуск не створює копію, а бадді, що вже працює,
помахає «Я тут! 👋».

Коли змінюється будь-який `.py` у цій папці, бадді сам перезапускається з новим кодом
(і стає на те саме місце). Якщо в коді синтаксична помилка, він не перезапускається,
а каже «Мій код зламався 🛠️». Помилки після перезапуску пишуться в
`~/.cache/claude-buddy/log.txt`.

### Claude Code 🤖

Бадді дізнається про події Claude Code через хуки. Додай у `~/.claude/settings.json`
(шлях заміни на свій):

```json
"hooks": {
  "Stop": [{"hooks": [{"type": "command", "timeout": 5,
    "command": "python3 /шлях/до/ClaudeBuddy/buddy_hook.py stop 2>/dev/null || true"}]}],
  "Notification": [{"hooks": [{"type": "command", "timeout": 5,
    "command": "python3 /шлях/до/ClaudeBuddy/buddy_hook.py notify 2>/dev/null || true"}]}]
}
```

- **Stop** — Claude закінчив відповідь → «Готово! ✅ (назва проєкту)».
- **Notification** — Claude чекає на дозвіл або на тебе → бадді двічі стрибає.

Хук передає подію через локальний сокет (`$XDG_RUNTIME_DIR/claude-buddy.sock`, доступ лише
в тебе) і завершується за частку секунди. Якщо бадді не запущений — нічого не станеться.

### Автозапуск при вході в систему

1. Відкрий `claude-buddy.desktop` і в рядку `Exec=` вкажи свій шлях до `buddy.py`.
2. Скопіюй файл в автозапуск:

```bash
cp claude-buddy.desktop ~/.config/autostart/
```

Вимкнути автозапуск: видали `~/.config/autostart/claude-buddy.desktop`.

## Як налаштувати під себе

Усе — на початку `buddy.py`:

- `BUDDY_PHRASES`, `ENGLISH_PHRASES`, `UKRAINIAN_QUOTES` — списки фраз, допиши свої;
- `TALK_INTERVALS` — скільки секунд між фразами для «Часто / Нормально / Рідко»;
- `SLEEP_IDLE_S`, `NIGHT_HOURS` — коли засинає; `POMODORO_*` — тривалість помодоро;
- `WALK_SPEED`, `CHASE_SPEED`, `CHASE_CHANCE` — швидкість і як часто ганяє курсор;
- `SPRITE` — сам персонаж «намальований» символами: `#` тіло, `o` очі, `L`/`R` ніжки;
- `PX_W`, `PX_H` — розмір одного «пікселя», тобто розмір персонажа;
- `skins.py` — аксесуари, компаньйони й сезонні образи (див. «Скіни»);
- `words.py` — слова для «Слова дня» і вікторини;
- `tamagotchi.py` — як швидко падають ситість і настрій.

Що де зберігається:

- `~/.config/claude-buddy/config.json` — твій вибір у меню (скіни, налаштування, місто, день народження);
- `~/.config/claude-buddy/state.json` — ситість, настрій, рекорд, де стояв бадді.

## Як це працює

- Вікно GTK без рамки з прозорим фоном; персонаж малюється кодом через Cairo.
- 30 разів на секунду функція `tick` оновлює **машину станів**:
  `rest` (відпочиває), `walk` (гуляє), `chase` (біжить за курсором), `held` (його несуть),
  `sleep` (спить), `game` (тікає від тебе в грі).
- Повільні перевірки (сезон, голод, сон, погода, зміни коду, помодоро) робить `periodic`
  раз на кілька секунд чи хвилин, а не 30 разів на секунду.
- Скільки ти не торкався клавіатури й мишки, бадді питає в GNOME (`org.gnome.Mutter.IdleMonitor`),
  тож сон працює навіть під Wayland.
- Погода — з [Open-Meteo](https://open-meteo.com/) (без ключа); запит робиться в окремому
  потоці, щоб бадді не завмирав. Надсилається лише назва міста й координати, які ти вказав.

| Файл | Що робить |
|---|---|
| `buddy.py` | вікно, малювання, меню, поведінка |
| `skins.py` | аксесуари, компаньйони, сезони й свята |
| `words.py` | англійські слова й вікторина |
| `tamagotchi.py` | ситість, настрій і збереження стану |
| `weather.py` | пошук міста й поточна погода |
| `claude_link.py` | сокет між хуком і бадді |
| `buddy_hook.py` | хук, який запускає Claude Code |
- Кліки ловить лише прямокутник довкола персонажа (`input_shape_combine_region`),
  тож решта вікна не заважає працювати.

## Обмеження

GNOME на Wayland не дозволяє звичайним вікнам самим ставати будь-де на екрані,
тому ClaudeBuddy працює через XWayland (`GDK_BACKEND=x11`). Через це він бачить курсор
лише над X11-вікнами й над самим собою. Тому за курсором він бігає, лише коли той
щойно рухався, а якщо «загубить» його — так і скаже 🤔
