# ClaudeBuddy 🧡

Маленький помаранчевий піксельний персонаж, який живе на робочому столі Linux:
гуляє по екрану, стежить за Claude Code, вчить з тобою англійську, нагадує про перерви
й коміти, танцює під музику і росте разом з тобою.

> Фанатський проєкт, натхненний маскотом із заставки Claude Code.
> Не пов'язаний з Anthropic.

## Встановлення однією командою (Ubuntu / GNOME)

```bash
sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0   # якщо ще немає
python3 install.py
```

`install.py` додає ярлик у меню програм, автозапуск при вході в систему, хуки Claude Code
в `~/.claude/settings.json` (чужі хуки не чіпає) і запускає бадді.

| Команда | Що робить |
|---|---|
| `python3 install.py --no-autostart` | без автозапуску |
| `python3 install.py --no-hooks` | без хуків Claude Code |
| `python3 install.py --uninstall` | прибрати ярлик, автозапуск і хуки, попрощатися з бадді |

Налаштування й прогрес (`~/.config/claude-buddy`) не видаляються навіть при `--uninstall`.
Запустити вручну: `python3 buddy.py`.

  показує, що Claude робить зараз: «Запускаю тести 🧪», «Комічу 💾», «Редагую buddy.py ✏️»,
  «Ой, команда впала 😬»;

- **рівні й досягнення 🏆:** досвід за помодоро, слова, ігри й задачі Claude; досягнення
  відкривають нові скіни (німб, капелюх-помідорку, диско-піджак…);
- **англійська 📚:** щоденний **урок** з планом до мети (за замовчуванням — 31 травня 2027),
  2094 слів від A1 до B1 у 19 темах, картки з вимовою, вікторина в обидва боки
  й розумне повторення (слова, в яких помиляєшся, повертаються частіше);
- **помодоро 🍅** і **нагадування ⏰** («нагадай о 15:00 подзвонити»);
- **турбота:** нагадує про перерву після 3 годин роботи, про незакомічені зміни, попереджає,
  коли процесор гарячий, пам'ять чи диск закінчуються;
- **тамагочі:** ситість і настрій падають з часом; голодний бадді блідне й ходить повільніше;
- **гра «Спіймай мене»**, компаньйон (котик, песик, курчатко), погода з парасолькою;
- **засинає**, коли тебе довго немає, і радіє, коли повертаєшся;
- сезонні образи на свята і твій день народження; кілька моніторів; звуки;
- **сам перезапускається**, коли змінюється його код, — оновлення видно одразу.

- Ситість і настрій, **🏆 рівень** (клік — відкриває прогрес), що зараз грає, погода.
- **📚 Урок** — сьогоднішні нові слова й повторення (див. «Англійська»).
- **Погодувати 🍎**, **Погратися ⚽** (вікторина або «Спіймай мене!»), **📖 Слово дня**.
- **🍅 Помодоро** — 25 хв роботи, 5 хв перерви, кожна четверта перерва — 15 хв.
- **⏰ Нагадування** — додати (о котрій або через скільки хвилин) чи видалити.
- **Скіни** й **Компаньйон 🐾**; закриті нагороди показані з 🔒 і умовою.
- **🔕 Не заважати** — без випадкових фраз, погоні, нагадувань про коміти й звуків
  (сповіщення Claude Code, помодоро й твої нагадування лишаються — ти їх сам увімкнув).
- **⚙️ Налаштування…** — вікно з вкладками (див. нижче), **🔄 Перезапустити**, **Вийти**.

## Англійська 📚

Мета — познайомитися з усіма словами словника (`wordlist.tsv`, від простих A1 до B1)
до дати мети й вивчити їх. Бадді сам рахує, скільки нових слів треба щодня: ті, що лишились,
ділить на дні до мети мінус два тижні (їх залишено на повторення). Для 2094 слів
і мети 31 травня це ~12 нових слів на день.

Урок (меню → **📚 Урок**) має три кроки:

1. **Картки** — нове слово, переклад, приклад і 🔊 вимова (через `spd-say`). Знаєш слово —
   «Я вже знаю ✓», і воно одразу піде у вивчені.
2. **Вікторина** — нові слова й ті, яких час повторити, в обидва боки: англійське → переклад
   і переклад → англійське. Помилився — слово повернеться наприкінці уроку.
   Клавіші: `1`–`4` — відповідь, `Enter` або пробіл — «Далі».
3. **Підсумок** — скільки зроблено, скільки вивчено і чи встигаєш до мети;
   кнопка «Ще 5 нових слів» для тих, хто хоче більше.

Повторення — за коробками Лейтнера: правильна відповідь відкладає слово на 1, 2, 4, 7, 14,
30 днів, помилка повертає на початок. Слово вивчене, коли воно в коробці 3 і вище.
Якщо урок ще не пройдено, бадді нагадає про нього (з 10:00, до трьох разів на день).
Дату мети, теми слів, нагадування й автовимову змінюють у налаштуваннях → «Навчання».

Щоб додати слово, допиши рядок у `wordlist.tsv`:
`слово<TAB>переклад<TAB>приклад<TAB>переклад прикладу<TAB>тема<TAB>рівень`.

### Як намалювати свій аксесуар

Відкрий `skins.py`: на початку файлу є схема сітки і покрокова інструкція.
Малюнок — із символів, де `.` прозоро, а кожна літера — колір із `palette`:

```python
"cap": Accessory(
    name="Кепка",
    art=(
        "....GGGGGGGGGG....",
        "...GGGGGGGGGGGGGG.",
    ),
    palette={"G": (0.2, 0.7, 0.3)},
    row=-2,  # на 2 рядки вище голови
),
```

Додай його в словник `HEAD`, `FACE` або `BODY` — і він з'явиться в меню.
Щоб зробити його нагородою, допиши в `LOCKED` і в `progress.ACHIEVEMENTS`.

## Claude Code 🤖

`install.py` (або кнопка у вкладці «Claude і код») додає чотири хуки:

| Хук | Коли | Що робить бадді |
|---|---|---|
| Stop | Claude закінчив відповідь | «Готово! ✅ (назва проєкту)» |
| Notification | Claude чекає на дозвіл або на тебе | двічі стрибає й кличе |
| PreToolUse | Claude запускає команду чи редагує файл | «Запускаю тести 🧪», «Редагую …» |
| PostToolUseFailure | команда впала | «Ой, команда впала 😬» |

Вручну: `python3 buddy_hook.py --install` / `--uninstall`. Хук передає подію через локальний
сокет (`$XDG_RUNTIME_DIR/claude-buddy.sock`, доступ лише в тебе), бере з неї тільки команду
чи ім'я файлу і завершується за частку секунди. Якщо бадді не запущений — нічого не станеться.

## Як налаштувати під себе

Константи на початку `buddy.py`:

- `BUDDY_PHRASES`, `ENGLISH_PHRASES`, `UKRAINIAN_QUOTES` — фрази; `TALK_INTERVALS` — як часто;
- `SLEEP_IDLE_S`, `NIGHT_HOURS` — сон; `POMODORO_*` — помодоро; `DANCE_BPM` — темп танцю;
- `GIT_*` — нагадування про коміти; `CPU_HOT_C`, `RAM_FULL_PCT`, `DISK_LOW_GB`,
  `WORK_NO_BREAK_S` — попередження про комп'ютер і перерви;
- `SPRITE`, `PX_W`, `PX_H` — сам персонаж і його розмір.

Інші файли: `words.py` (слова), `progress.py` (досвід і досягнення), `sounds.py` (мелодії),
`tamagotchi.py` (як швидко падають ситість і настрій).

Що де зберігається (`~/.config/claude-buddy/`):

| Файл | Що в ньому |
|---|---|
| `config.json` | твій вибір у меню й налаштуваннях |
| `state.json` | ситість, настрій, рекорд, де стояв бадді |
| `progress.json` | досвід, досягнення, статистика, «зошит» зі словами |
| `reminders.json` | нагадування, що ще не спрацювали |

Звуки генеруються в `~/.cache/claude-buddy/sounds/`, помилки пишуться в
`~/.cache/claude-buddy/log.txt`.

## Як це працює

- Вікно GTK без рамки з прозорим фоном; персонаж малюється кодом через Cairo.
- 30 разів на секунду `tick` оновлює **машину станів**: `rest`, `walk`, `chase`, `held`,
  `sleep`, `game`. Повільні перевірки (сезон, голод, сон, музика, нагадування, коміти,
  комп'ютер, зміни коду) робить `periodic` раз на кілька секунд чи хвилин.
- Час без активності бадді питає в GNOME (`org.gnome.Mutter.IdleMonitor`), музику —
  у плеєрів через MPRIS; обидва — через D-Bus, тож працює й під Wayland.
- Мережа (погода) і `git status` виконуються в окремих потоках, щоб бадді не завмирав.
- Кліки ловить лише прямокутник довкола персонажа (`input_shape_combine_region`).
- Коли змінюється будь-який `.py`, бадді перевіряє, що код компілюється, і перезапускається
  на тому самому місці. Персонаж може бути лише один: другий запуск змусить його помахати.

| Файл | Що робить |
|---|---|
| `buddy.py` | вікно, малювання, меню, поведінка |
| `settings_window.py` | вікно налаштувань |
| `skins.py` | аксесуари, компаньйони, нагороди, сезони й свята |
| `words.py` | читання словника, вікторина, розумне повторення |
| `wordlist.tsv` | сам словник: слово, переклад, приклади, тема, рівень |
| `lesson.py` | план щоденного уроку до мети |
| `lesson_window.py` | вікно уроку |
| `progress.py` | досвід, рівні, досягнення, статистика |
| `tamagotchi.py` | ситість, настрій і стан бадді |
| `music.py` | що грає (MPRIS) |

## Тести

```bash
python3 -m unittest
```

Тести перевіряють голод, дати свят (зокрема Великдень), повторення слів, рівні й досягнення,
нагадування, розбір `/proc`, пошук незакомічених змін, звуки й встановлення хуків.
Вони працюють у тимчасових папках і не чіпають твій прогрес.

## Обмеження

- GNOME на Wayland не дозволяє звичайним вікнам самим ставати будь-де на екрані, тому
  ClaudeBuddy працює через XWayland (`GDK_BACKEND=x11`). Через це він бачить курсор лише
  над X11-вікнами й над самим собою, тож ганяє курсор, тільки коли той щойно рухався.
- Spotify зі Snap розповідає про пісні лише програмам без пісочниці: бадді, запущений
  з автозапуску чи меню програм, його бачить; запущений з пісочниці (наприклад, з терміналу
  всередині snap-редактора) — ні. Музика з браузера та інших плеєрів працює завжди.
