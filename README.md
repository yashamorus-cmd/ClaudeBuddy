# ClaudeBuddy 🧡

Маленький помаранчевий піксельний персонаж, який живе на робочому столі Linux:
гуляє по екрану, інколи бігає за курсором і каже фрази — поради, англійські вислови
з перекладом і українські цитати.

> Фанатський проєкт, натхненний маскотом із заставки Claude Code.
> Не пов'язаний з Anthropic.

## Що вміє

- гуляє у випадкові точки екрана й відпочиває, кліпає очима;
- інколи біжить за курсором (якщо його видно — див. «Обмеження»);
- раз на 1–3 хвилини каже фразу в хмаринці: 58 фраз без повторів, поки не прозвучать усі;
- завжди поверх вікон, але кліки повз персонажа проходять крізь нього.

## Керування

| Дія | Що станеться |
|---|---|
| Лівий клік | підстрибне на місці |
| Подвійний клік | одразу скаже наступну фразу |
| Затиснути й тягнути | перенесеш його в інше місце |
| Правий клік | меню: скіни, сезонні скіни, «Вийти» |

## Скіни 🎩

Правий клік → вибери аксесуар у кожному слоті (їх можна поєднувати):

- **Головний убір:** шапка-біні, корона, навушники, циліндр
- **Обличчя:** окуляри, сонцезахисні окуляри
- **Одяг:** вишиванка, краватка-метелик

Вибір запам'ятовується в `~/.config/claude-buddy/config.json`.

**Сезонні скіни** вдягаються самі (вимикаються галочкою в меню):

| Коли | Образ |
|---|---|
| 15 грудня – 15 січня | 🎅 шапка Санти |
| 25 жовтня – 2 листопада | 🎃 капелюх відьми, гарбузовий колір, світні очі |
| 23–25 серпня | 💙💛 вишиванка і прапорець |
| 14 лютого | ❤️ сердечко над головою |

Сезон замінює лише ті слоти, які використовує: наприклад, шапка Санти замінить корону,
але сонцезахисні окуляри лишаться.

Подивитися сезонний скін у будь-який день:

```bash
BUDDY_DATE=2026-12-25 python3 buddy.py
```

### Як намалювати свій аксесуар

Відкрий `skins.py`: на початку файлу є схема сітки і покрокова інструкція.
Коротко — малюнок із символів, де `.` прозоро, а кожна літера — колір із `palette`:

```python
"cap": Accessory(
    name="Кепка",
    art=(
        "....GGGGGGGGGG....",
        "...GGGGGGGGGGGGGG.",
    ),
    palette={"G": (0.2, 0.7, 0.3)},
    row=-2,  # на 2 рядки вище голови
),
```

Додай його в словник `HEAD`, `FACE` або `BODY` — і він з'явиться в меню.

## Встановлення (Ubuntu / GNOME)

Потрібні Python 3 і GTK 3 з підтримкою Cairo:

```bash
sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0
```

Запуск:

```bash
python3 buddy.py
```

Другий запуск нічого не робить — персонаж може бути лише один.

### Автозапуск при вході в систему

1. Відкрий `claude-buddy.desktop` і в рядку `Exec=` вкажи свій шлях до `buddy.py`.
2. Скопіюй файл в автозапуск:

```bash
cp claude-buddy.desktop ~/.config/autostart/
```

Вимкнути автозапуск: видали `~/.config/autostart/claude-buddy.desktop`.

## Як налаштувати під себе

Усе — на початку `buddy.py`:

- `BUDDY_PHRASES`, `ENGLISH_PHRASES`, `UKRAINIAN_QUOTES` — списки фраз, допиши свої;
- `PHRASE_INTERVAL` — як часто він говорить (у секундах);
- `WALK_SPEED`, `CHASE_SPEED`, `CHASE_CHANCE` — швидкість і як часто ганяє курсор;
- `SPRITE` — сам персонаж «намальований» символами: `#` тіло, `o` очі, `L`/`R` ніжки;
- `PX_W`, `PX_H` — розмір одного «пікселя», тобто розмір персонажа;
- `skins.py` — аксесуари й сезонні образи (див. «Скіни»).

## Як це працює

- Вікно GTK без рамки з прозорим фоном; персонаж малюється кодом через Cairo.
- 30 разів на секунду функція `tick` оновлює **машину станів**:
  `rest` (відпочиває), `walk` (гуляє), `chase` (біжить за курсором), `held` (його несуть).
- Кліки ловить лише прямокутник довкола персонажа (`input_shape_combine_region`),
  тож решта вікна не заважає працювати.

## Обмеження

GNOME на Wayland не дозволяє звичайним вікнам самим ставати будь-де на екрані,
тому ClaudeBuddy працює через XWayland (`GDK_BACKEND=x11`). Через це він бачить курсор
лише над X11-вікнами й над самим собою. Тому за курсором він бігає, лише коли той
щойно рухався, а якщо «загубить» його — так і скаже 🤔
